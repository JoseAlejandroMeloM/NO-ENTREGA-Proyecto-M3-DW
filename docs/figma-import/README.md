# Figma import pack

Figma's free plan only allows a few AI tool calls per month, so the AI could not edit the file directly. These files go into the Figma file by hand: drag and drop, about 10 minutes, no cost.

Figma file: https://www.figma.com/design/szQV2p4RZ3kvWKrq0siSz9

| Folder | What | Figma page |
|---|---|---|
| `wireframes/` | 26 low-fidelity wireframes, S01–S26 (SVG, 1440 px wide). Generated by `node scripts/wireframes.mjs` from the screen list in `docs/spec/06-screens.md` | **1 · Wireframes** |
| `final/` | Final designs of the missing screens S01–S04 and S19–S26 (PNG, 1440 px wide), captured from the running app (`npm run demo`) | **3 · Final design** |

The design system (page 2) and the final designs S05–S18, with S08 annotated, are already in the file.

## Steps
1. Open the file and go to page **1 · Wireframes**. Select all 26 `.svg` files in `wireframes/` in Finder and drag them onto the canvas. Figma turns each SVG into a frame with editable text and shapes.
2. With all the new frames still selected, press **Shift + A** (auto layout) and set the direction to wrap or horizontal, so they line up. Or arrange them by hand in screen order.
3. Go to page **3 · Final design**. Drag the 13 `.png` files from `final/` next to the existing S05–S18 frames. Name each one by its file name (S01 Landing, …).
4. Delete the leftover helper node (`4:2`) if it is still on a page.
5. Copy the file link (Share → Copy link). It is already in the README; check that **anyone with the link can view** it.

## Regenerating
- Wireframes: `node scripts/wireframes.mjs` (no dependencies).
- Final screens: start `npm run demo`, then take 1440 px screenshots of the routes in `docs/spec/06-screens.md` (logged in as `ventas@distrinorte.test` for S19–S25, and as `caja@tienda.test` opening `/app/orders` for the 403 page).
